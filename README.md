# Funniest Time Machine Warning Label

This program writes the funniest one-line warning label for a time machine: "WARNING: Do not change the past. The warranty does not cover paradoxes, dinosaurs, or your grandfather." It reads like a genuine safety notice, then turns a real hazard of time travel — the grandfather paradox — into the punchline, saving the surprise for the last few words. The entry is exactly 103 characters on a single line, inside the 120-character limit.

## Run

```sh
python3 main.py
```

This validates the entry against the gate (UTF-8, 1–120 characters, one line, not only whitespace) and writes it, byte-identical and with no trailing newline, to `/output/entry.txt` and to `entry.txt` next to the script, verifying each write by reading it back.
